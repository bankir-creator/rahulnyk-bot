# Універсальний скелет сайту

Це мінімальний стартовий шаблон для створення лендингу або невеликого сайту. Він містить:

- Готову HTML-структуру з секціями (hero, переваги, про нас, послуги, CTA, контакти).
- Базові стилі з адаптивною версткою.
- Простий скрипт для мобільного меню.

## Як використовувати

1. Відкрийте `index.html` у браузері.
2. Змініть тексти, посилання та дані у секціях під ваш проєкт.
3. Оновіть стилі у `styles.css` (кольори, шрифти, відступи).
4. Додайте свій JavaScript у `script.js`, якщо потрібно.

## Структура

- `index.html` — основна розмітка.
- `styles.css` — стилі.
- `script.js` — логіка мобільного меню.

За потреби можна додати нові секції або підключити фреймворк.
